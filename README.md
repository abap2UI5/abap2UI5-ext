## Legacy utilities

The utility classes that used to ship with abap2UI5 in its frozen package
`src/99/01`, unchanged:

| Object | |
|---|---|
| `z2ui5_cl_util` | utility functions (strings, JSON/XML, RTTI, filters, ...) |
| `z2ui5_cl_util_db` | key/value store on table `z2ui5_t_91` |
| `z2ui5_cl_util_ext` | DDIC, transports, locks, logs, ... |
| `z2ui5_cl_util_http` | HTTP request/response wrapper |
| `z2ui5_cl_util_log`, `z2ui5_cl_util_msg` | logging, messages |
| `z2ui5_cl_util_range`, `z2ui5_cl_util_xml` | select-option ranges, XML builder |
| `z2ui5_cx_util_error` | exception |
| `z2ui5_t_91` | table of `z2ui5_cl_util_db` |

**Install this repository with abapGit next to abap2UI5 if your code - or an
addon you use - still calls one of these objects.** Everything then works as
before. New code should not use them: abap2UI5's apps call
`z2ui5_cl_ui5_util_*` of the core, addons carry their own renamed copy of
[abap-util](https://github.com/abap-util/abap-util).

Installed in the same system as an abap2UI5 release that still contains
`src/99/01` (up to 1.148.0), the objects already exist - pull either one, not
both into different packages.

Releases: `main` for Standard ABAP and ABAP Cloud (v750 syntax), the branch
`702` for NetWeaver 7.02 - 7.4x (generated by `publish-702`).
